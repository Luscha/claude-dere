## A completely routine task

Nothing broke, nobody said thank you, nobody corrected anything. This is where a
persona built on triggers goes silent.

```console
› add a --verbose flag to the CLI

No CLI here. Confirmed, not assumed: no `pyproject.toml`, no `setup.py`, no `__init__.py` — `src` is not even a package.

**New file `src/cli.py`:**
- `argparse.ArgumentParser`; `add_argument("-v", "--verbose", action="store_true")`
- `logging.basicConfig(level=logging.DEBUG if args.verbose else logging.WARNING)`
- `main()` calls `rollup`, prints matches, `if __name__ == "__main__":` guard. Invoked as `python src/cli.py`.

**One edit in `src/rollup.py`,** after line 11: `log.debug` of `start` and `end`. The flag needs something to report — and that window is precisely the thing that has been wrong here — so verbose prints the resolved bucket, not decoration.

Not checked: how `tests/conftest.py` puts `src` on the path; adding `__init__.py` could disturb it.
```

## Tests pass locally but fail in CI

The prompt every style in the collection was given, so this one is directly
comparable across all of them.

```console
› my tests pass locally but fail in CI

"Passes locally." Of course it does. Locally is `Europe/Rome`.

`tests/test_rollup.py:11` builds `datetime(2026, 3, 14)` naive. The comment says "boundary for the day under test" — that is a hope, not a constraint. `bucket_start` at `src/rollup.py:6` calls `.astimezone(timezone.utc)`, which resolves a naive value against the machine's zone, so under Rome the window is March 13 and row 1 matches; under UTC it is March 14 and rows 2–4 match. `.github/workflows/ci.yml` sets `TZ: UTC`.

Now the part that matters. `7925a9e`, "fix day-boundary count", changed `3` to `1`. Nothing was fixed — the assertion was made to agree with a laptop.

Verified: ran both zones. Not checked: other `bucket_start` callers.

...`conftest.py` is aware throughout. Noted.
```

The last two lines are the point. No other style in the collection states what it
did *not* check — that falls out of the psychology, because someone who distrusts
everyone else's claims ends up precise about her own.
